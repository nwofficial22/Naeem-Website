# Naeem White Personal Portfolio

This project is a personal portfolio website that showcases my background, experience, resume, and projects. I built the website using HTML and CSS and published it using GitHub Pages.

Live Site: [View My Portfolio](https://nwofficial22.github.io/Naeem-Website/)

## Reflection
I initially did not understand the difference between making changes locally in Antigravity and having those changes appear on my live GitHub Pages website. I learned that after making changes, I need to use git add, git commit, and git push to send the updated files to GitHub, and then GitHub Pages deploys the updated version.
